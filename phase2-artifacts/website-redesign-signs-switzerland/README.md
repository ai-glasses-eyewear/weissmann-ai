Tick the warning signs you recognise; the twelve are grouped by **what they cost**, not how they look —
revenue-blocking (mobile friction, slow mobile load, broken forms, no CTA, security warning), compounding
(unclear offer, weak trust, no analytics, search/technical), operational (nobody can get in, painful editing,
inconsistent branding). Verdict weights revenue-blocking most: 3+ → "redesign overdue"; 1–2 (esp. with
compounding) → "targeted fixes first"; only compounding → "worth improving, not urgent"; only operational →
"a process conversation, not a redesign"; nothing → "re-check periodically." Checked revenue-blocking signs
surface in a "fix these first" list. Honest framing throughout; a diagnostic, not a quote. No invented claims,
no personal data, nothing stored. Verified: verdict logic asserted at all tier boundaries.
