Three tools in one. **(1)** A 9-point checklist scorer (same domain, message-match headline, single offer/CTA,
reduced nav, above-the-fold offer, PageSpeed-checked mobile load, real-smartphone test, matching trust
elements, own conversion goal) with a live score bar and a prioritised "als Nächstes angehen" list. **(2)** A
message-match tester: type the ad promise and the landing-page headline → it shows the shared significant
keywords (stopword-filtered word overlap), a reflection helper, not a score. **(3)** A timed 5-second test
(countdown → the two questions "Was wird angeboten? Was soll ich als Nächstes tun?"). Plus a Quality-Score
explainer (three components; the landing page moves only the LP-experience one) with the diagnostic-not-auction
fact and the actual-CPC formula, all from Google Ads Help. **No invented Swiss stat** — the WordStream ranges
(≈2.35 % median / 5.31 % / 11.45 %) are labelled international context, and the article's "no reliable Swiss
study" is stated. No personal data, nothing stored. Verified: score/overlap logic asserted; timer is a clean
state machine.
