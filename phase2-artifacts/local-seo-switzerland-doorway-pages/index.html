Doorway-page risk checker: does this location earn its own page?

A dedicated page for Zurich, Zug, Basel or Geneva is worth building only when that location shows real, verifiable evidence. This tool runs the article’s four-part evidence test on one candidate location at a time and flags whether it is a genuine local page or a thin, duplicated doorway page — the exact failure mode Google’s own spam policy names.

Step 1 · Your business model

The honest number of location pages depends on business model, not ambition. Pick the one that fits.

Business model

Skip entirely The correct number of location pages is zero.

With only one location, there is nothing to test — not because any test failed, but because there is only one location in the first place. Your homepage and a claimed, well-kept Google Business Profile already do the entire local-search job. Building a location-page architecture for a problem that does not exist is effort spent on the wrong thing.

Step 2 · Describe one candidate location

Answer for a single city, canton or service area. Nothing you type leaves your browser — use a placeholder like “Zug” if you prefer.

1 · Staffed presence or sustained local service base

A lease, a listed employee, a phone answered locally — or, for a service-area model, a real ongoing pattern of jobs completed here over a meaningful period. Not an aspiration to expand.

2 · Independently distinguishable content

Is there something true of this location that is not equally true of the others? A named local team, reviews that mention this branch or city, real local examples, hours or access notes that differ from the next town over.

3 · Genuinely separable search demand

Is there a query pattern for this location that a shared “our services plus coverage area” page would not already satisfy — beyond the same sentence with the city name in the heading?

4 · A named owner who will keep it current

Is someone accountable for updating this specific page’s local facts — staff, hours, reviews — as they change?
