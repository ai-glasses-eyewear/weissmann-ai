The hreflang <head>


        

        
The alternate list is identical on every page; only the self-referencing canonical changes per locale. It is reciprocal — each locale lists all the others and itself — because Google ignores the whole annotation “if two pages don’t both point to each other.” x-default points at the default locale as a fallback, not a ranking signal.

    How this very site is wired (a live example)
    
    
    
      
    Germanweissmann.ai/leistungen/ki-webentwicklung/  default · no prefix
    
      
    Englishweissmann.ai/en/services/ai-web-development/
    
      
    Italianweissmann.ai/it/servizi/sviluppo-siti-web-ai/
    
      
    Frenchweissmann.ai/fr/services/developpement-web-ia/
    
    
    
    
    One localized slug per language — not four copies of ki-webentwicklung with a country code stapled on. German is tagged de-CH (Swiss High German spells with ss, not ß); English, Italian and French use the plain codes. This article itself exists in English only, so its hreflang set holds exactly one alternate (en, pointing at itself) plus an x-default to that same URL — no invented link to a translation that was never written.
    
    
    Where a build fits: the Starter Website (CHF 880, regular CHF 2’490) sets up the technical SEO and GEO foundation but is one language — additional languages aren’t included. Larger builds are quoted at the Business tier (CHF 4’990) and the Complex tier (from CHF 9’900).
